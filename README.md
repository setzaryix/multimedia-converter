# Multimedia Converter

A basic multimedia converter for **video and audio files**, designed with a focus on **screen reader accessibility**.

This project uses **FFmpeg** under the hood and provides a simple, accessible workflow for converting media files into different formats.

---

## Features

* **Batch conversion**
  Convert multiple video or audio files at the same time.

* **Customizable formats via presets**
  Easily add or modify output formats using a JSON preset file.

---

## 🧩 Preset Configuration

Conversion formats are defined in:

```
preset/preset.json
```

Each preset is based on **FFmpeg command-line arguments**.
You can add new formats or modify existing presets by editing this file.
